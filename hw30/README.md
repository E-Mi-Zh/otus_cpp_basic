# Домашнее задание №8 «Многопоточный "взлом"»

## Цель

Написать многопоточное приложение на основе std::thread

## Задание

Требуется с помощью многопоточности ускорить программу, которая добавляет в конец
входного файла строку "He-he-he" и произвольные четыре байта, подобранные так,
чтобы CRC32 хеш полученного нового файла совпал в точности с CRC32 исходного.

## Дополнительные задания

### Оптимизация

Исправить многократные повторяющиеся вычисления

### Динамическая балансировка

Определять оптимальное количество потоков в зависимости от нагрузки.

## Критерии оценки

* Исходные коды сохранены на GitHub.
* Проект собирается с помощью cmake без ошибок и предупреждений (при включенных опциях -Wall -Wextra -pedantic).
* В результате работы программы создан новый файл с добавленными данными и хешем CRC32, совпадающим с исходным.
